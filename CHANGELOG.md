# Changelog — MotionKit PP

## 2.13.0 — 2026-10-26
- Fixed: the panel could open completely black after restarting the computer
- Fixed: the license was lost when the computer name changed or after a reboot
- The panel never stays black: loading screen, automatic safe mode and a clear
  "MotionKit could not start" screen with Reset & reload
- License works fully offline after activation (silent check at most once a month,
  being offline never locks the panel)
- Activation also works when Premiere Pro is blocked in a firewall
- Automatic updates from GitHub (Update available → Install update)
- New Mac installer, uninstallers and Fix Black Screen tools
- Built-in boot log for faster support

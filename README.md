# MotionKit PP — Premiere Pro toolkit by Motionsfly

All-in-one motion toolkit panel for **Adobe Premiere Pro** (Windows + macOS).

## Download

➡️ **[Download the latest version](https://github.com/Motionsfly/motionkit_pp/releases/latest)**

A license key is required. Buy MotionKit PP on [Gumroad](https://officialmotionsfly.gumroad.com/).
One license works on 2 computers and works offline after activation.

## Install

1. Download `MotionKit_PP_vX.X.X.zip` from the latest release and unzip it.
2. Close Premiere Pro.
3. **Windows:** double-click `Install on Windows.bat` · **Mac:** right-click `Install on Mac.command` → Open
4. Premiere Pro → **Window → Extensions → MotionKit PP - Motionsfly**

Full help: `Installation Guide.html` inside the ZIP.

## Updates

Already installed? MotionKit PP checks this page automatically and shows an
**Update available** card in the panel — click **Install update** and restart Premiere Pro.

## Black or empty panel?

Close Premiere Pro and run **Support Tools → Fix Black Screen** from the ZIP.
Still not working? Email the `MotionKit-PP-log.txt` file (the tool puts it on your Desktop).
